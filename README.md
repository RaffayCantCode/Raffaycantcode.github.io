# Muhammad Raffay Asif - Portfolio

This is my personal portfolio website showcasing my work in Game Development, Web Applications, and AI tools. 

## Tech Stack
- **React** (Vite)
- **React Router** for page navigation
- **CSS** with a custom "raw and fun" design system
- **Lucide React** for icons

## Features
- Cinematic scroll-by-scroll project showcases.
- Dynamic video backgrounds for project detail pages.
- Fully responsive design optimized for mobile and desktop.
- Automated deployment to GitHub Pages via GitHub Actions.
